# Angel Anu Mathew: portfolio

- Edit text and links: `src/data/portfolio.ts`
- Photos and screenshots: `public/images/`, listed in `src/data/portfolio.ts`
- Colours for light and dark mode: top of `src/styles.css`
- File names are case-sensitive.

Run locally: `npm install`, then `npm run dev`.
Deploy: upload these files to a GitHub repository and import it in Vercel (Vite is detected automatically).
