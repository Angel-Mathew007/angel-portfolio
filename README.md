## A little about me

I'm an Information Technology graduate from Navi Mumbai. I enjoy building things that can look at images and video, understand what's happening, and help people act on it. This is called computer vision, and it's a part of AI.

I studied at Fr. Conceicao Rodrigues Institute of Technology and have done research at TIFR Mumbai and IISER Mohali.

## Some things I've built

**Checking tiny wires on sensors.** At TIFR, I built a system that inspects very fine wire connections on silicon sensor modules, a job that was otherwise done by eye. It comes with a desktop app that shows the results and creates reports.

**Noticing when someone falls.** At IISER Mohali, I worked on a system that watches a camera feed, spots a fall and sends an SMS alert.

**Dubbing videos into other languages.** This tool listens to a video, translates the speech and matches the lip movements to the new language. It received an Indian Copyright registration.

**Predicting health risks.** A simple app where you enter health details or upload a cell image, and a model estimates the risk of certain diseases. It is a student project, not a medical tool.

I've also built a career guidance platform and a canteen ordering system. You'll find all of these on the website.

## What you'll see on the site

## For the curious (and the developers)

The site is made with React, TypeScript and Vite. To run it on your computer, install [Node.js](https://nodejs.org), open this folder in a terminal and type:

```bash
npm install
npm run dev
```

Then open the link that appears. Most of the website's text is in `src/data/portfolio.ts`.
